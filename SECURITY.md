# Security Policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities, exposed credentials, authentication weaknesses, or other sensitive security findings.

Use GitHub's private vulnerability reporting feature for this repository when available. If private reporting is unavailable, contact the repository owner privately and include only the minimum information needed to reproduce the issue.

Do not include live credentials, tokens, private keys, personal data, or production secrets in reports, screenshots, logs, commits, issues, or pull requests.

## Repository security controls

This project uses automated dependency updates, CI tests, repository secret scanning, and CodeQL analysis. Changes to `main` should be merged through reviewed pull requests with required checks enabled in repository rules.
